Как получить InitData
  1. Открой Telegram Web в браузере и вызови DevTools клавишей F12.
  2. Перейди во вкладку Network, открой игру и введи login в строке поиска.
  3. Открой найденный запрос, перейди в Payload и скопируй значение поля initData целиком.
  4. Если запроса нет, можно скопировать accessToken и refreshToken из Application → Storage → Local Storage и войти по ним во вкладке «По токенам».

АВТОПРОХОЖДЕНИЕ

Автопрохождение

При нулевой энергии бот восстановит 100 бодряков за 8 мыла. При включении потребуется подтверждение.

Укажите доверенные ID через запятую, пробел или точку с запятой. Бот берёт первый доступный ID из пула; он ждёт только уже отправленную заявку доверенному ID, а ручная заявка другому игроку не блокирует отправку.

Мыло запрещено Роль меняется только после безопасного завершения текущего цикла. Щит не покупается автоматически; шкафы открываются только за жетоны события.

КАК ЭТО РАБОТАЕТ

Правила и стратегия

ВарщикЗа 90 бодряков готовит партию. Клиентского лимита накопления нет: бот продолжает работу и отправляет весь готовый запас указанному барыге.
БарыгаЗа 90 бодряков находит клиента. Клиентского лимита накопления нет: бот продолжает работу и отправляет весь готовый запас указанному варщику.
СмотрящийЗа 50 бодряков раскрывает входящее предложение или ведёт расследование на 90 действий. Настоящую роль цели сервер не показывает, поэтому догадки чередуются.
НаградаБазовый состав сделки задаёт сервер по уровню события: новые тиры открываются на 1, 10, 20 и 30 уровнях. Подтверждённого множителя за накопленное количество в активной логике клиента нет.
Предложения и смена ролиПока одно предложение ждёт партнёра, новые партии продолжают готовиться. После принятия бот отправляет накопившийся запас. Смена роли выполняется только после безопасного завершения текущего цикла.
